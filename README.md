# Taste Of Fire Restaurant Website

Professional responsive restaurant website for Taste Of Fire, Gonda, Uttar Pradesh.

## Working features
- Responsive restaurant landing page
- Mobile navigation
- Menu modal with sample menu items
- Click-to-open photo gallery
- WhatsApp reservation request form
- Call button
- WhatsApp button
- Google Maps directions
- Opening hours and contact details
- Accessible modal close controls and Escape-key support

## Stack
HTML5 • CSS3 • Vanilla JavaScript

## Run locally
Open `index.html` in a browser or serve the folder with a static web server.

## Important
Menu prices are sample web content based on supplied information. Confirm the restaurant's current menu before publishing exact prices.
